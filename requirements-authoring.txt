#     webserver/      the local chat UI over ingest.py's index
#
# Deliberately not in requirements.txt: none of this runs on the server, and
# qdrant-client alone drags in grpcio, which is a long build on a Pi and a
# large layer everywhere. See docker-compose.rag.yml for the Qdrant service.
