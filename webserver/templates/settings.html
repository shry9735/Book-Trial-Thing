n8n Webhook

Messages are POSTed as {"message": "…"}. The server proxies this call, so n8n doesn't need to allow CORS.

Leave both blank if your webhook has no authentication. Common examples: header Authorization with value Bearer <token>, or X-N8N-Api-Key.
